# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | ✅ |

## Reporting a Vulnerability

Si encuentras una vulnerabilidad en este repositorio:

1. **No** crees un issue público
2. Envía un email al maintainer
3. Describe el problema con detalles
4. El equipo responderá en 24-48 horas

## Ámbito

Este repositorio contiene archivos de configuración y templates para proyectos frontend. Los usuarios son responsables de:

- Validar dependencias externas
- Revisar código antes de copiarlo
- Aplicar sus propias políticas de seguridad

## Best Practices

Cuando uses estos skills en proyectos:

- Mantén dependencias actualizadas
- Usa environment variables para secrets
- Implementa rate limiting en APIs
- Valida todos los inputs del usuario
- Follow OWASP guidelines
